### E-commerce Demand Forecasting & Stock Prediction — Final Project

Collaborative End-to-end Machine Learning project to forecast demand and estimate stock needs using approximately **150,000 records**. Includes feature engineering, time-series forecasting, temporal validation, backtesting, MLflow experiment tracking, data drift monitoring, and Streamlit deployment.

**Documented results:** **Precision@5 of 100%** for the selected stock-prediction approach and **2.36% MAPE** for monthly demand forecasting.  Top-5 categories correctly identified in 4/4 backtesting years.
Stack: Python · Scikit-learn · LightGBM · MLflow · Streamlit · Power BI
